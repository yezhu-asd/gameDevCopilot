# GameDevCopilot 简历项目描述

## 一句话项目定位

一个「一句话生成可玩游戏原型」的 AI Agent 系统：用户输入自然语言，Agent 自主完成需求解析、知识检索、代码生成、引擎无头验证与自动修复，产出可运行的 Godot 游戏。

## 简历写法（3-5 行）

> **GameDevCopilot — 一句话生成游戏原型的 AI Agent 系统**（Python / LangGraph / RAG / Godot）
>
> 1. 基于 LangGraph 搭建「生成→规范→验证→修复」有状态工作流，构建 Agent 自主规划、工具调用、结果校验闭环；Godot 引擎无头模式自动运行验证，失败自动回炉修复，支持多轮迭代。
> 2. 构建游戏设计知识库与 RAG 检索（bge-m3 向量化 842 文本块 + FAISS），按需求语义检索相关设计文档注入上下文，提升复杂游戏一次生成成功率。
> 3. 预置平台跳跃/Roguelike/塔防三类已验证骨架模板，Agent 在骨架上填充玩法而非从零生成，保证结构正确性、降低 token 成本。
> 4. 提供 FastAPI + 网页 Demo，实时展示 RAG 检索、生成、无头验证全过程与生成的代码，一键提交、轮询状态、代码查看。
> 5. 真实生成验证：塔防、平台跳跃、贪吃蛇、Roguelike 均可生成并运行；修复过 StaticBody 误报、tscn 资源顺序、Godot3 遗留 API 等工程问题。
